# Working in this repo

This repository is public. Anything committed, pushed, or written in a pull request, issue or comment can be read by anyone, and stays in history even after it's edited.

## What goes in

- Skills: a folder per skill with a `SKILL.md` and any references or scripts it needs.
- Examples are made up. No customer or client names, no customer data, no real people.
- No licensed standard text. Cite criteria and clauses by id, never quote them.
- No links or paths to private repositories, internal documents or tools.
- Read every file in full before it goes up.

## Commits, branches and pull requests

- Nothing is committed or pushed without the maintainer's go-ahead. The maintainer merges.
- Commit messages say what changed.
- Branch names describe the change, e.g. `add-tabletop-skills`.
- Pull request descriptions say what changed and why. Nothing else: no links to AI sessions or chats, no internal notes about who approved what.
- No AI session, chat or workspace links anywhere: not in commits, pull requests, branch names, files or comments.

## Before every push

Check the diff, every commit message and the pull request description for session or chat links, internal ids and paths, customer or partner names, and personal email addresses. If anything turns up, stop and fix it before pushing. If something has already been pushed, tell the maintainer instead of trying to rewrite it away: edit history and force-pushed commits stay visible.
